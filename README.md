# 📣 AdShooter — โปรแกรมยิงแอด

เว็บแอปสำหรับจัดการแคมเปญโฆษณา Facebook / TikTok / Shopee ในที่เดียว พร้อมระบบวิเคราะห์ประสิทธิภาพ
ระบบยิงแอด/หยุดแอดอัตโนมัติ (Auto-Pilot) และ **กล่องข้อความรวม** สำหรับตอบลูกค้าจากหลายเพจ/ร้านค้า
โดยไม่ต้อง login Facebook หรือ Shopee โดยตรง

ออกแบบให้ใช้งานได้ทันทีด้วย **ข้อมูลจำลอง (mock data)** โดยไม่ต้องรอสมัคร/รออนุมัติ API ของแพลตฟอร์มไหนก่อน
แล้วค่อยกรอก API จริงทีหลังเมื่อพร้อม ระบบจะสลับไปใช้ข้อมูลจริงให้อัตโนมัติทันทีที่กรอกครบ (ดูสถานะ "เชื่อมแล้ว"
กับ "โหมดจำลอง" ได้ตลอดเวลาจากป้ายสีในแต่ละหน้า)

## ฟีเจอร์หลัก

- **แดชบอร์ด** — ดูทุกแคมเปญทุกแพลตฟอร์มรวมกัน พร้อมยอดใช้จ่าย/คลิก/คอนเวอร์ชัน เปิด-ปิด-ลบแคมเปญได้
- **สร้างแคมเปญใหม่** — เลือกแพลตฟอร์ม บัญชี วัตถุประสงค์ และงบประมาณ/วัน
- **วิเคราะห์ประสิทธิภาพ** — CTR / CPC / CPA / Conversion Rate พร้อมคะแนนจัดอันดับเทียบกับแคมเปญอื่นที่
  กำลังรันอยู่ด้วยกัน (percentile-based ไม่ใช่เกณฑ์ตายตัว) และกราฟแนวโน้มรายวัน
- **ระบบอัตโนมัติ (Auto-Pilot)** — ปิดเป็นค่าเริ่มต้นเสมอ เปิดแล้วจะหยุดแคมเปญที่ไม่มีประสิทธิภาพ และเพิ่มงบ
  ให้แคมเปญที่ทำผลงานดี โดยพยายามสั่งที่ตัวแพลตฟอร์มจริงด้วยถ้าเชื่อมต่อไว้แล้ว (ไม่ใช่แค่ในระบบ) — มีระบบ
  ป้องกันหลายชั้น: ไม่ลบแคมเปญ, ไม่เปิดแคมเปญที่ถูกหยุดกลับมาเอง, เว้นระยะกันเพิ่มงบถี่ ๆ, ยกเว้นแคมเปญ
  เป็นรายตัวได้
- **กล่องข้อความรวม (ใหม่)** — รวมแชทจาก Facebook Messenger และ Shopee Chat ของทุกบัญชีที่เชื่อมไว้มาไว้
  ที่เดียว ตอบได้จากหน้าโปรแกรมโดยตรง ไม่ต้อง login Facebook/Shopee เอง ข้อความจาก Facebook เข้าแบบ
  เรียลไทม์ผ่าน webhook (ดูการตั้งค่าใน `docs_api_setup_guide.md`)
- **หลายบัญชีต่อแพลตฟอร์ม** — เชื่อมได้หลายเพจ/หลายร้านค้าในแพลตฟอร์มเดียวกัน
- **ส่งออก Excel** — ออกรายงานแคมเปญทั้งหมดเป็นไฟล์ .xlsx

## เริ่มใช้งานแบบไหนดี

| ต้องการ | แนะนำ |
|---|---|
| ใช้คนเดียวในเครื่องตัวเอง เร็วที่สุด ไม่ต้อง deploy | double-click `install-windows.bat` (Windows) หรือ `install-mac.command` (Mac) |
| แบ่งให้ทีมงาน/คนอื่นเข้าใช้ผ่านลิงก์เว็บ หรืออยากใช้ฟีเจอร์กล่องข้อความแบบเรียลไทม์ | deploy ขึ้นเว็บตาม `DEPLOY-FREE.md` (ฟรี ไม่ต้องใช้บัตรเครดิต) หรือ `DEPLOY.md` (ตัวเลือกอื่น) |

> ⚠️ ฟีเจอร์กล่องข้อความแบบเรียลไทม์ (Facebook webhook) **ต้องมี URL สาธารณะแบบ HTTPS** เท่านั้นถึงจะใช้ได้
> — รันแบบเดสก์ท็อปในเครื่องตัวเองเฉย ๆ จะใช้ฟีเจอร์นี้ไม่ได้ (ฟังก์ชันอื่นใช้ได้ปกติทุกอย่าง) ต้อง deploy ก่อน

## รันแบบเดสก์ท็อป (ในเครื่องตัวเอง)

**Windows**: ติดตั้ง [Python](https://www.python.org/downloads/) (ติ๊ก "Add Python to PATH" ตอนติดตั้งด้วย)
แล้ว double-click ไฟล์ `install-windows.bat`

**Mac**: ติดตั้ง [Python](https://www.python.org/downloads/) แล้ว double-click ไฟล์ `install-mac.command`
(ถ้า Mac ไม่ยอมเปิดเพราะเตือนความปลอดภัย ให้คลิกขวา > Open แทนการ double-click ครั้งแรก)

ครั้งแรกที่รันจะติดตั้งไลบรารีและสร้างข้อมูลตัวอย่างให้ดูก่อน (ลบได้จากหน้าแดชบอร์ด) ครั้งต่อไปแค่ double-click
ไฟล์เดิมซ้ำเพื่อเปิดโปรแกรมได้เลย

## รันด้วยมือ (สำหรับคนคุ้นเคยกับ command line)

```bash
python -m venv venv
source venv/bin/activate        # Windows ใช้: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # แก้ ADMIN_USERNAME / ADMIN_PASSWORD ในไฟล์นี้ก่อนใช้งานจริง
python seed_demo_data.py        # ไม่บังคับ แค่สร้างข้อมูลตัวอย่างให้ดูก่อน
python app.py                   # เปิดที่ http://127.0.0.1:5000
```

## การตั้งค่า API จริง

ไปที่หน้า **"ตั้งค่า API"** ในโปรแกรม กรอก credentials ของแพลตฟอร์มที่พร้อมแล้ว (ไม่ต้องกรอกครบทุกแพลตฟอร์ม
พร้อมใช้ทีละแพลตฟอร์มได้) ดูขั้นตอนขอ API/permission ของแต่ละแพลตฟอร์มแบบละเอียดได้ที่
[`docs_api_setup_guide.md`](./docs_api_setup_guide.md)

## โครงสร้างโปรเจกต์ (สำหรับคนจะแก้โค้ดต่อ)

```
app.py                 เส้นทาง (routes) หลักของเว็บแอป + ระบบ login
config.py              จัดการ credentials หลายบัญชีต่อแพลตฟอร์ม
storage.py             เก็บข้อมูลแคมเปญ (data/campaigns.json)
analytics.py           คำนวณ CTR/CPC/CPA + จัดอันดับ + กราฟ SVG
automation.py          ระบบยิงแอด/หยุดแอดอัตโนมัติ
inbox.py               กล่องข้อความรวม + webhook รับข้อความ Facebook
connectors/            ตัวเชื่อม API ยิงแอดแต่ละแพลตฟอร์ม (live-with-fallback-to-mock)
messaging/             ตัวเชื่อม API ส่งข้อความแต่ละแพลตฟอร์ม
templates/, static/    หน้าเว็บ (Flask + Jinja2)
desktop.py             ตัวเปิดโปรแกรมแบบเดสก์ท็อป
seed_demo_data.py       สร้างข้อมูลตัวอย่าง (รันซ้ำได้ ไม่ทับข้อมูลจริงที่มีอยู่แล้ว)
```

## คำถามที่พบบ่อย

**ข้อมูลเก็บไว้ที่ไหน?** โหมด desktop (รันในเครื่องตัวเอง): ไฟล์ JSON ที่โฟลเดอร์ `data/` ข้างโปรแกรม (หรือ
ที่ตั้งไว้ใน `DATA_DIR`) — backup ง่าย ๆ แค่ copy โฟลเดอร์นี้ไว้ ส่วนโหมดเว็บที่ deploy (ตั้งค่า `DATABASE_URL`
ไว้) ข้อมูลทั้งหมดเก็บถาวรในฐานข้อมูล Postgres ที่ชี้ไว้แทน ไม่ใช่ไฟล์บนดิสก์ของเซิร์ฟเวอร์ — ดู `DEPLOY.md`

**ลบข้อมูลตัวอย่างยังไง?** กดปุ่มลบที่หน้าแดชบอร์ด/กล่องข้อความได้ตามปกติ หรือ (โหมด desktop) ลบไฟล์
`data/campaigns.json` และ `data/conversations.json` แล้วรีสตาร์ทโปรแกรม

**ลืมรหัสผ่านเข้าระบบ?** แก้ค่า `ADMIN_PASSWORD` ใน `.env` (หรือ environment variable ของแพลตฟอร์มที่ deploy)
แล้วรีสตาร์ท
